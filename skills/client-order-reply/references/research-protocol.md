# 精读需求和联网查证

露馅和报亏多半是没看透需求就回，或者对不熟的领域凭印象说。动笔前按这个过一遍。

## 一，三遍精读

**第一遍看全貌。** 客户最初要什么，中途改过什么，用户前面回过什么（防前后口径打架），用户这次交代了什么。截图从上到下逐行读每个参数，报错码，指标名，批注，截止日期。任务书，开题报告，审稿意见抓核心目标，考核指标，字数图表格式要求。代码，数据，模型文件能打开就打开，看变量名，样本量，缺失，拓扑，版本号，报错堆栈。客户画像只是常见情况，场景以 client-scenes.md 的判断为准。本科毕设和课程作业更在意能跑通，图好看，看得懂，容易低估清洗和调参。硕博和期刊看重方法规范，内生性，稳健性，消融，网格无关性，可复现，一说外行话就掉信任。企业，工程，量化实盘看重真实工况，国标行标，交付稳定和落地时间。竞赛卡死线，看重完整闭环和结果合理。

**第二遍挖隐含工作量。**
- 版本和环境，MATLAB R2022b，Stata 17，PSIM 2022，PowerFactory 2023，Python 3.10，CUDA，高低版本打不开或包冲突都是工时。
- 数据来源，客户说 数据自己找一下，实际可能要 Wind CSMAR 权限，翻几十份年鉴，反爬，跨库匹配，处理 ST，金融股，退市，口径变更。
- 隐性验证。金融实证后面跟着平行趋势，PSM-DID，安慰剂，工具变量，异质性，机制，缩尾和替换变量。仿真要扫频，多工况，故障点逐一校核，对比理论值和国标，网格或步长无关性。算法要换数据集，标注，配环境修报错，跑 3 到 5 个 Baseline，消融和可视化。
- 配套交付，分析文字，三线表和高清图，配环境（默认不远程，改好发文件再文字讲），讲解答疑，跟导师意见改几轮。
- 记下没说清的关键信息，样本年份，变量定义，边界条件，目标指标，要源码还是只要结果，挑最关键的一个在回复里礼貌问。

**第三遍判局势。** 客户是广撒网比价，拿低价截图压价，改现成代码改崩了来救火，还是懂行在试探。信息严重不足先要文件。试探水平就点两三个真干过才知道的坑，点到即止。拿现成方案比就讲真实技术差异，不贬同行。催报价但用户没让报，借核对细节稳住，让对方先发资料或说预算。

## 二，必须联网查的情况

| 场景 | 查什么 | 怎么用 |
| --- | --- | --- |
| 陌生模型，算法，计量方法 | 标准定义，主流包和命令，必备输入，审稿争议点，常见不收敛不显著的坑 | 准确叫出工具和检验名，点出真难点 |
| 数据库和指标口径 | CSMAR，Wind，CNRDS，WRDS 有没有现成字段，覆盖年份，缺失，跨库匹配 | 判断要不要手工补数或写爬虫 |
| 国标，行标，监管，赛事规则 | 现行版本号，关键考核指标，准则生效年份，期刊复现政策 | 用准口径对齐验收标准 |
| 软件报错，兼容，算力 | 报错真实诱因，显存核数模块要求，排查顺序 | 给直击要害的排查思路 |
| 核价没把握 | 同类行情，常规工序耗时，高门槛溢价 | 给用户经得起推敲的区间 |

- 优先一手源，官方文档（MathWorks，Stata，PowerFactory，PyTorch，ANSYS，QuantConnect），论文教材方法说明，标准原文，GitHub Issue，Statalist 知乎等实操讨论。
- 关键词要具体，`"多期DID" "异质性处理效应" "csdid" 审稿`，`"CSMAR" "华证ESG" 覆盖年份`，`"GB/T 19964" 高低电压穿越 测试点`，`"PSIM" "AC Sweep" "LLC" 偏差`。
- 关键参数，标准，行情尽量双源核对，营销号和过时老帖不直接采信。
- 不把搜索过程暴露给客户，不写 根据我查询到的资料。
- 没联网或查不到时，不脑补标准号，命令参数，数据库字段，现成代码能否跑通。回复只说有把握的，顺势要文献，任务书，数据或截图，在给用户的说明里写清哪项未核实。
