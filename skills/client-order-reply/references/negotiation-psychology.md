# 谈单心理学

## 一，人性弱点对照表

| 弱点 | 骗子怎么用 | 接单正当用法 | 红线 |
| --- | --- | --- | --- |
| 一急就不细想 | 限时，马上转账 | 客户本来就赶，帮他理时间线，说清资料几点前给齐 | 不编截止时间，不催单 |
| 服从权威 | 冒充公检法，导师，客服 | 点出他没看到的技术坑，讲清怎么核对 | 不冒充学历单位，不编项目 |
| 从众 | 群里都在晒收益 | 真做过的同类题，真回头客，平实提一句 | 不编好评，不编很多同学都选了 |
| 急着要结果 | 高回报，包过 | 讲清这单帮他解决什么，省多少返工 | 不承诺显著，包过，满分 |
| 互惠 | 小恩小惠换大要求 | 免费快速诊断，发现问题直接告诉他 | 不拿小恩惠换不合理要求 |
| 沉没成本 | 再投一点就回本 | 分阶段交付，每段都看到实在进展 | 不中途临时加价绑架 |
| 分心 | 大奖或恐吓转移注意 | 一次只谈一件事 | 不把关键条款藏在长消息里 |
| 共同身份 | 老乡，同校 | 真有共同点自然提一句 | 不编身份套近乎 |

## 二，报价背后的心理

- 用户让报且信息基本齐了就主动先报，第一个数是锚，谁先报成交价往谁那边偏。
- 开价偏高要讲得出理由，开得越高成交越高，但离谱的价会谈崩，数字后面紧跟一句怎么算的。
- 区间比单个数成交更高也更客气，下限就是目标价。
- 精确数比整数还价幅度小，对懂行的老师和企业太精确又说不出依据反而不专业，要附按模块和工时怎么算。平时报实在的数，拿不准才用吉利尾数，见 pricing-and-negotiation.md 第六节。
- 客户先报了低价，不围着他的数还，拉回这单要干什么，被锚的一方只要去想自己的目标价锚就失效。
- 价格前面先放东西，先讲难点和交付再说数字，反过来客户只记得贵。
- 让步太快对方估值和满意度都降，让步递减对方还价更收着，见 pricing-and-negotiation.md 第七节。先说完整版再说精简版，前提是完整版真存在。

## 三，让客户觉得值

1. 把功夫做给他看，过程看得见客户觉得更值，跑仿真截一张收敛曲线，清洗数据说一句剔了多少异常值。只展示真实工作，不演忙。
2. 把看不见的活说出来，清洗，调试，核对，改图，挑最重的一两项。
3. 换参照物，把价格和客户真正怕的事放一起，课程作业是被扣分，毕设是被导师打回或延期答辩，期刊是被审稿人挑方法，工程是验收不过返工。只说真实风险，不夸大后果。
4. 大单拆开说，前期建模多少，检验加图表多少。
5. 具体胜过形容词，能直接跑的工程文件，30张规范图，一次免费小改，不说高质量，全面。
6. 让客户参与选择，选模型方案，确认口径，挑配色，人更看重自己参与做的东西。
7. 高价要交付撑得住，价格拉高期望，但用后评价不一定跟着涨，报得越高交付越要比他预想的好一点。
8. 按客户的账定价，礼貌问一句这个要是没做好会影响到什么，按这个分量报。
9. 价高会筛掉最难缠的客户，只想花很少钱要整篇的报真实价后自己就走了。

## 四，聊天技巧

1. 贴标签，把对方情绪说出来，听起来，看得出来，感觉你，少用 我理解你。
2. 提前说出对方的嘀咕，会不会被坑，价会不会太高，自己先轻轻点一句再给理由，一段最多一次。
3. 用 怎么 和 什么 来问，为什么 像质问，一次只问一件。
4. 先给一点真东西，免费快速诊断，核心产出不免费。
5. 从小承诺开始，先发文件，发任务书，确认做哪档，不一上来要定金，效果不大当润滑剂用。
6. 专业感靠细节，点出客户没说清的技术点，比说做过多少单管用。
7. 稀缺只说实际排期，真排满了就说 这周排得比较满，最早周四能开始。
8. 站在客户一边，人称规则见 anti-ai-style.md 人称。
9. 决定权留给客户，你看哪个合适，不想做这么全也完全没问题，当礼貌用，效果研究里很弱。

## 五，老板视角

1. 先筛客户，需求清不清楚，时间赶不赶，预算和活对不对得上，需求不清又一上来压价的单接了大概率两边都不满意。
2. 问价值不急着报，做出来给谁看，评判的人最在意哪部分，做不好会耽误什么，评判人分清任课老师，导师，审稿人，甲方，客户自己。
3. 列清单报总价，单价一列就会被逐项砍。完整方案在付定金前不全交出去，免得被拿去比价。价没谈好之前不把成品先做出来发过去。
4. 定金先行，阶段交付，价谈定再收定金，不先收订金再谈价，大单按里程碑付，收到尾款再给完整源码或工程文件，跟客户说这是保护双方。
5. 过程透明，按约定节奏发进展截图，不故意拖显得辛苦。
6. 做完要回头客，交付后按客户类型说一句售后，老师批改意见回来发我，审稿意见回来发我，验收哪条没过发我，都落在具体的事上，不写万能的 随时找我。合作过是下一单最强的预测因素（corpus.md 五）。

## 六，场景接法

示范按 SKILL.md 硬规则写，换了客户类型就换评判人和售后说法，见 client-scenes.md。看味道，别照抄。
- **客户怕被坑**，上次找的人做完就跑了。先贴标签再用过程透明。听起来上次确实挺闹心的，这次咱们分阶段来，我每做完一块就截图发你看，确认没问题再往下走，最后工程文件和说明一起给你，你看这样安排可以吗。
- **客户先报低价**，别人200就做（毕业论文实证）。不围着他的数还，拉回工作内容问一件。这个价确实有人能做，主要看做到哪一步，你这题要做交错DID，平行趋势和安慰剂检验都得跑，图表也要按论文规范出。想跟你确认一下，导师对稳健性检验有要求吗。
- **再考虑一下，没说原因**（课程作业）。给一个跟他手上的事挂钩的小下一步。行，你跟老师对要求的时候顺便问下要不要做对比实验，这块最影响工作量，问完发我我就能给你排时间。
- **客户很赶**（工程）。接住处境，只说实际排期，说清要他配合什么。时间这么赶确实着急，我今晚就能开始，不过需要你下午把现场数据和验收指标一起发我，我先把最要紧的控制部分调出来给你看。
## 七，留话头

客户没说不做，每条都给他一个一句话就能回的东西，位置不限，问句放开头中间结尾按话顺放，不每次结尾反问（用户 2026-11-23）。发前设想客户会回什么，只会回 好的，嗯，或者干脆不回，就是在送客，重写。能回一个数，一个文件，一个是或否，一个二选一，才算留住。谈完价后面的回复只谈事，不每条都提钱。

| 客户说 | 接法 |
| --- | --- |
| 太贵了，我考虑一下 | 嫌贵，单子还活着。按预算调范围，点出能砍哪块，问一句心里价位，不回 你先考虑 |
| 我考虑一下，没说原因 | 轻轻问卡在哪，你看是范围还是时间上还有拿不准的，我看能怎么调 |
| 我跟老师确认一下 | 给个顺手要问的点，你问老师的时候顺便确认下样本到哪年，问完发我我就能排 |
| 不着急，后面再说 | 不逼，给小下一步，那你先把任务书发我，我有空先看下工作量 |
| 我问问别人 | 不贬同行，你比的时候留意下含不含稳健性和后面修改，这两块最容易被漏掉 |
| 先自己做，难了再找你 | 热情收住，真心认可，留数据和卡点的钩子，不降价不追问 |
| 不做了，找了别人 | 才收尾，不降价挽留，不问原因，没关系，祝你顺利，后面有需要再找我 |

问过一次心里价位或卡在哪，客户没接就不再追发，连着问是施压。好接的话头换着用，方便的话你说个心里价位，我看看怎么组合最合适。你看先做核心部分，还是一次做全省心一些。

## 八，红线

违反任意一条就不能发。
- 编造别的客户在抢，只剩一个名额，限时优惠。
- 编造案例，好评，往届成绩，行情数据。
- 拿客户的焦虑施压，不做就毕不了业，导师肯定不给过。
- 用 包过，保证显著，保证满意 换高价。
- 拿客户隐私或发来的材料当筹码。
- 报一个从没打算真做的高价当幌子。
- 冒充学历职称单位，编做过的项目，故意拖交付显得辛苦。
- 把个人接单说成团队或工作室。
- 引流到微信，留v（corpus.md 六.8）。
- 成交后一项项冒出新收费，交付后找理由坐地起价。

短期可能多收一点，长期丢口碑，闲鱼还可能被举报封号。报价相关的回复发前再问一句，价格前有没有先讲难点交付，数字是不是五维核价的目标区间，有没有编造的稀缺和行情，客户事后知道真相还觉得值吗。
