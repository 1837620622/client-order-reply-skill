# 金融、经济、会计与量化专题知识库

本领域客户跨度极大（本科毕设、经管硕博论文、顶刊投稿、商赛、券商/行研实习、企业估值、个人/机构量化实盘），专业口径极严，一句话说外行就会立刻丧失议价权。涉及冷门指标、最新期刊方法或特定数据库字段时，务必先联网检索核实再回复。

## 一、公司金融与实证计量（Stata / R / Python）

### 核心方法与最新审稿风向
- 基准面板回归：双向固定效应（行业/个体 + 年份 FE，`reghdfe`）、聚类稳健标准误（公司层面或行业-年份双重聚类）、高维固定效应。
- 因果识别与内生性处理：
  - 多期/交错 DID：现在顶刊和严格高校已普遍质疑传统 TWFE 存在异质性处理效应偏误（负权重问题），常需补充 平行趋势动态检验（Event Study）、安慰剂检验（随机抽样 500/1000 次画核密度图）、Goodman-Bacon 分解、Callaway & Sant'Anna（`csdid`）、Sun & Abraham（`eventstudyinteract`） 或 堆叠 DID（Stacked DID）。
  - PSM-DID：逐年匹配 vs 混合匹配、最近邻（1:1 / 1:2 / 卡尺）vs 核匹配、平衡性检验与共同支撑域。
  - 工具变量（IV-2SLS）：弱工具变量检验（Kleibergen-Paap rk Wald F > 10）、不可识别检验（LM）、过度识别（Hansen J），注意外生性逻辑能不能自圆其说（如份额移动法 Bartik IV、地理坡度/历史距离交互项等）。
  - 其他识别：Heckman 两步法（处理样本选择偏误，必须有排他性约束变量）、断点回归（RDD，含操纵检验 McCrary 与带宽敏感性）、合成控制法（SCM / SDID）、双重机器学习（DML）。
- 机制检验（极高频踩坑点）：传统温忠麟三步法在《管理世界》《中国工业经济》《经济学（季刊）》等顶刊及多数高校答辩中已被普遍质疑，现在主流改用 江艇（2022）两步法（重点证 X→Y 和 X→M，M→Y 靠理论文献支撑），或辅以分组交互项调节效应。
- 稳健性与异质性：替换核心解释/被解释变量口径、改变样本区间（如剔除 2020 疫情年或 2008 金融危机）、1% 双边缩尾（Winsorize）、滞后一期缓解反向因果、增加城市/宏观层面控制变量、产权性质（国企/民企）/地区/行业竞争度/生命周期异质性（注意做组间系数差异检验如 `suest` 或费舍尔组合检验 `bdiff`）。
- 空间计量与门槛回归：空间权重矩阵构建（0-1 邻接、地理距离、经济距离、经济地理嵌套）、全域/局域莫兰指数（Moran's I）、LM/LR/Wald 检验选模型（SDM / SAR / SEM）、直接效应与间接溢出效应分解（`xsmle`）；面板门槛回归（Hansen `xthreg`）与门槛值置信区间图。
- 文本分析与前沿指标：年报 MD&A 爬虫抓取（巨潮资讯网）、Python 分词与词典法（如数字化转型、绿色关注度、经济政策不确定性 EPU、管理层语调）、Word2Vec 扩词或 FinBERT/大模型打分。

### 数据源与清洗隐性工作量（压低“现成代码/很简单”预期）
- CSMAR 国泰安：最常见坑是财报里合并报表（Typrep='A'）和母公司报表（Typrep='B'）混在一起、季报半年报和年报混在一起，不筛干净直接重复合并；另外不同年份会计科目名称变更、ESG 不同评级机构（华证、商道融绿、彭博、润灵环球、Wind ESG）覆盖公司数和起始年份差别极大。
- Wind / Choice / iFinD：债券、基金、高频行情、一致预期、并购事件导出常有条数配额限制，多表拼接需严格按代码和日期清洗。
- CNRDS：绿色专利（IPC 分类号匹配）、媒体报道情绪、供应链集中度、政府补助明细。
- 城市/省级统计年鉴与公报：大量缺年、区划变更（如莱芜并入济南、巢湖拆分、撤县设区）、统计口径前后不一致，常需手工翻地方统计公报补数，再用插值法校验。
- 美股 WRDS（CRSP / Compustat / IBES / Execucomp）：跨库主键匹配（GVKEY / PERMNO / CIK / CUSIP，需用 CCM linking table）极易丢样本或日期错位。
- 标准金融清洗流程：剔除金融保险类行业（证监会 2012 分类 J 类）、剔除当年 ST/*ST/PT 及退市样本、剔除资不抵债或核心变量缺失样本、连续变量上下 1% 缩尾。

### 必问客户的关键问题
1. 样本范围和年份定了没（A 股上市公司、地级市还是美股/银行，哪年到哪年），数据自己有还是需要这边从库里导。
2. 要做到哪一层（只要基准回归，还是连内生性、平行趋势、机制、异质性、稳健性整套，要不要三线表和结果分析文字）。
3. 导师或参考论文有没有指定具体软件（Stata/R/Python）和指标测算口径。

## 二、资产定价、时间序列与宏观金融

### 核心方法与专业切入点
- 因子模型与事件研究：CAPM、Fama-French 三因子/五因子、Carhart 四因子、Fama-MacBeth 截面回归（注意 Newey-West 滞后调整解决序列相关）、事件研究法（估计窗/事件窗选择、市场模型算正常收益率、CAR/BHAR 及跨截面 t 检验或 BMP 检验）。
- 投资组合优化：马科维茨均值-方差（有效前沿、夏普比率最大化、最小方差，注意协方差矩阵估计误差导致极端权重，常需 Ledoit-Wolf 收缩估计或加入卖空/权重上限约束）、Black-Litterman（融合主观观点与市场均衡先验）、风险平价（Risk Parity）、HRP 层次风险平价。
- 时间序列与波动率建模：
  - 单位根平稳性检验（ADF / PP / KPSS）必须先做，非平稳强行回归就是伪回归；同阶单整看协整（Johansen / EG 两步法）建 VECM。
  - VAR / SVAR：滞后阶数筛选（AIC/BIC/HQIC）、稳定性检验（AR 特征根全部在单位圆内）、格兰杰因果、脉冲响应（IRF）与方差分解（FEVD）。
  - GARCH 族：先做 ARCH-LM 检验确认存在条件异方差再建 GARCH / EGARCH / GJR-GARCH（捕捉杠杆非对称效应）、DCC-GARCH 动态条件相关。
  - 金融风险溢出前沿方法：Diebold-Yilmaz（DY 2012/2014）溢出指数（基于广义预测误差方差分解 GFEVD，避免 Cholesky 排序依赖）、BK 频域溢出（Barunik & Krehlik）、分位数溢出（QVAR）、TVP-SV-VAR（时变参数随机波动，常跑 MCMC 抽样，耗时长且须检 Geweke 收敛和无效因子）、Copula / CoVaR / MES 尾部系统性风险测度。

### 隐性工作量与必问点
- 跨市场高频/日频数据（如美股、A 股、原油、黄金、汇率、加密市场）存在交易日历不同步、节假日错位与时区差异，对齐方式直接影响溢出结果。
- 必问：标的资产清单、数据频率（日/周/月/分钟）、时间跨度、是否要做滚动窗口动态溢出图。

## 三、衍生品定价、固定收益与金融风控

### 核心方法与专业切入点
- 期权与结构化产品定价：Black-Scholes-Merton（BSM）解析解、隐含波动率反推与波动率曲面拟合（SVI / SABR）、二叉树/三叉树、有限差分法（显式/隐式/Crank-Nicolson 求解 PDE）、蒙特卡洛模拟（几何布朗运动、Heston 随机波动率、路径依赖型如亚式/回望/障碍/雪球期权，美式期权用 Longstaff-Schwartz 最小二乘蒙特卡洛 LSM）。
  - 痛点：蒙特卡洛路径数不够收敛方差大（常需对偶变量或控制变量缩减方差）；雪球/敲入敲出期权在临界障碍线附近 Gamma 和 Vega 剧烈跳变，差分算 Greeks 极易抖动失真。
- 固定收益与利率期限结构：收益率曲线拟合（Nelson-Siegel / Svensson、样条插值）、久期（麦考利/修正/有效久期）、凸性、关键利率久期（KRD）、短期利率模型（Vasicek / CIR / Hull-White）、债券信用利差影响因素。
- 市场风险与信用风控：
  - 市场风险：VaR 与 ES（历史模拟、方差-协方差、蒙特卡洛、GARCH-EVT 极值理论），必须做回溯检验（Kupiec POF 失败率检验、Christoffersen 独立性检验）。
  - 信用评分卡与机器学习风控：好坏客户定义与滚动率/Vintage 分析、时间外样本切分（OOT 跨期验证，绝不能只靠随机切分骗指标）、样本不平衡处理、最优分箱（卡方/决策树分箱并保证 WOE 单调性）、WOE 编码与 IV 筛选、VIF 共线性剔除、逻辑回归转标准分（Base Score / PDO）、XGBoost / LightGBM 对比与 SHAP 解释；核心评估指标 KS、AUC、Gini、PSI（群体稳定性）。
  - 企业违约与结构化模型：KMV（用股权市值和波动率联立非线性方程迭代反推资产价值和资产波动率，再算违约距离 DD）、Altman Z-Score、CreditMetrics。

### 必问点
- 是纯教学/论文验证还是对接真实市场合约数据，定价要不要输出 Greeks 和敏感性曲面，风控数据集是自己有脱敏明细还是用公开数据集（如 Lending Club / Home Credit / 德国信用数据）。

## 四、量化交易与策略回测

### 主流平台与核心雷区
- 平台生态：聚宽（JoinQuant）、米筐（RQAlpha）、掘金、Backtrader、VN.PY、Qlib、QuantConnect、TradingView（Pine Script）、MT4/MT5（MQL4/MQL5）、实盘 API（CTP、IBKR、OKX/Binance 等）。
- 一眼看穿是否懂行的关键坑：
  - 未来函数（Look-ahead Bias）：财务因子必须按财报实际公告日（ann_date）对齐，不能拿报告截止日（end_date）往回用；日线信号不能拿当日收盘价算完又按当日收盘价成交。
  - 复权陷阱：算技术指标信号用前复权或后复权，但撮合成交、计算持股手数（A 股 100 股整数倍）和分红配股现金流如果直接套前复权价会产生失真或负价格问题。
  - 幸存者偏差与交易摩擦：全市场回测必须包含已退市股票；必须模拟 A 股 T+1、涨跌停板无法成交、停牌、印花税、佣金和滑点；因子研究必须看 IC / RankIC / ICIR、分层单调性、换手率扣费后净收益。
  - 过拟合防护：样本内/样本外切分、滚动 Walk-Forward 验证、参数高原检验，绝不承诺实盘必赚。

### 必问点
- 跑在哪个平台或本地 Python 框架、交易标的（A 股/期货/ETF/美股/加密）和频率（日线/分钟/Tick）、数据源有没有现成接口、只要回测报告还是连带实盘下单风控模块。

## 五、公司估值、财务建模与会计分析

### 核心技能与专业细节
- 动态三表联动模型（Excel）：利润表、资产负债表、现金流量表全自动联动，核心验算铁律是资产负债表每一期必须严格配平（Balance Check = 0）。常见翻车点：折旧摊销明细表与固定资产净值脱节、营运资本（应收/存货/应付）变动方向写反、利息费用与现金/债务形成循环引用（Circular Reference）未规范处理开关、留存收益漏扣股利。
- DCF 现金流折现估值：
  - 严防口径错配：FCFF（公司自由现金流）必须用 WACC 折现得到企业价值 EV，再减净债务、少数股东权益、加非经营性资产得股权价值；FCFE 用股权成本 Ke 折现直接得股权价值，两套混着用直接不及格。
  - 关键参数出处：无风险利率（10 年期国债收益率）、可比公司去杠杆再加杠杆 Beta（Hamada 公式）、ERP、税后债务成本、永续增长率 g（须低于长期名义 GDP 且小于 WACC）或退出倍数法（Exit Multiple）、WACC × g 二维敏感性矩阵与足球场估值图（Football Field）。
- 相对估值与并购：PE / PB / PS / EV/EBITDA / EV/Sales 可比公司筛选与中位数估值、LBO 杠杆收购债务偿还瀑布与 IRR/MOIC 敏感性、M&A 合并增厚/摊薄分析（Accretion/Dilution）。
- 财务分析与会计准则：杜邦分析、哈佛分析框架、盈利质量与舞弊识别（Beneish M-Score、修正 Jones 模型操纵性应计利润）、中国企业会计准则（CAS）与国际准则（IFRS）关键差异（新收入准则 CAS 14、新租赁准则 CAS 21、新金融工具准则 CAS 22 / IFRS 9 预期信用损失 ECL）。

### 必问点
- 目标公司是哪家、预测几年、只需要 DCF 估值表还是带完整三表联动和可比公司分析、要不要配套行研/估值说明文字（如商赛/CFA Research Challenge/课程报告）。

## 六、银行、保险精算与链上/DeFi 金融

- 商业银行：净息差 NIM 拆解、资产负债管理（ALM）、利率敏感性缺口、久期缺口、流动性指标（LCR / NSFR）、资本充足率（巴塞尔协议 III 风险加权资产 RWA）、不良贷款率与拨备覆盖率分析。
- 保险与精算：生命表与寿险保费/准备金计算、非寿险索赔准备金链梯法（Chain-Ladder）/ BF 法、GLM 车险费率厘定。
- Web3 / 链上金融分析：Dune Analytics SQL 查询、Etherscan/链上交易流追踪、AMM 流动性池（Uniswap V2/V3）无常损失与集中流动性收益模拟、稳定币脱锚与清算机制回测。
