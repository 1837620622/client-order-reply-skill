# 嵌入式，自动化控制，PLC 与机器人知识库

## 一、单片机与嵌入式（STM32，51，ESP32，Arduino，树莓派）

- 常见需求：课设和毕设小系统（温湿度监测，智能家居，小车，门禁），传感器驱动，通信（UART，I2C，SPI，CAN，Modbus），上位机，物联网上云（MQTT，阿里云，OneNET），FreeRTOS 多任务。
- 工作量真正花在哪：硬件到手和调试，传感器型号不同驱动就不同，实物调试比写代码费时间。只要仿真（Proteus）和要实物差别很大。
- 必问点：只要仿真还是要实物，芯片和模块型号定了没，要不要画板，要不要上位机或手机端，要不要论文和演示视频，实物谁来买和寄。

## 二、PLC 与工业自动化（西门子 TIA Portal S7-1200/1500，S7-200 SMART，三菱 GX Works，欧姆龙）

- 常见需求：控制流程设计（交通灯，传送带分拣，水箱液位，电梯），梯形图，I/O 分配表，主电路和控制电路图，组态画面（WinCC，组态王，MCGS），PLCSIM 仿真联调。
- 实操坑：软件版本不兼容（TIA 低版本打不开高版本工程），仿真和实物 I/O 地址要对上，PID 指令块参数整定。
- 必问点：指定的 PLC 型号和软件版本，要不要组态画面，是否联调仿真，要不要电气图纸和说明书。

## 三、控制理论与算法仿真（MATLAB/Simulink）

- 常见需求：PID 整定，状态空间和 LQR，MPC，滑模控制，自抗扰 ADRC，模糊 PID，观测器，系统辨识，根轨迹和 Bode 图分析，稳定性和鲁棒性对比。
- 实操坑：模型参数要来源可靠，离散化和采样时间，执行器饱和，算法对比要同一个被控对象同一组扰动才公平。
- 必问点：被控对象模型有没有给，对比哪几种算法，看哪些指标（超调，调节时间，稳态误差，抗扰），要不要硬件在环。

## 四、机器人与 ROS

- 常见需求：机械臂正逆运动学和轨迹规划（Robotics Toolbox，MATLAB），移动机器人 SLAM 和导航（ROS1 或 ROS2，Gazebo），路径规划算法（A*，RRT，DWA）对比。
- 实操坑：ROS 版本和 Ubuntu 版本要对应，仿真环境搭建本身就花时间，实物机器人远程调不了。
- 必问点：ROS 版本，仿真还是实物，用哪个机器人模型，要演示视频吗。

## 五、本领域常见交付物

源码和工程，能跑的仿真文件，接线图或原理图，I/O 分配表，流程图，演示视频，说明文档，课设或毕设报告配套图表。
