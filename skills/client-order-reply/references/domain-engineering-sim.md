# 电气、电力、控制、机械 CAE/CAD、硬件与系统仿真知识库

工程与仿真单的最大特点是：**模型“能点运行不报错”只算完成了 30%，真正费时间的是参数整定、多工况收敛、边界核对、和理论/国标对得上**。客户常拿网上几百块的现成模型来压价，直接用真实工程卡点讲透即可。

## 一、电力电子与电机控制

### 常用工具与核心技术点
- **软件**：PSIM、MATLAB/Simulink、PLECS、LTspice、Saber、Maxwell 联合仿真、CCS/STM32 代码生成。
- **典型拓扑**：Buck / Boost / Buck-Boost、全桥/半桥/推挽、LLC 谐振变换器、移相全桥、双向 DAB（单/双/三移相 SPS/DPS/TPS）、图腾柱 PFC、三相两电平/三电平 NPC/T 型并网逆变器、模块化多电平 MMC、固态变压器 SST。
- **核心控制算法**：电压电流双闭环 PI、比例谐振 PR（追踪交流正弦）、重复控制、无差拍/模型预测控制（MPC）、滑模控制（SMC）、自抗扰（ADRC）、电机 FOC 磁场定向控制、SVPWM、无感观测器（滑模 SMO / 锁相环 PLL / 高频注入）、构网型控制（VSG 虚拟同步机）、弱电网阻抗重塑与稳定性分析。
- **真内行实操坑（一眼显专业）**：
  - **开关频率与仿真步长**：高频开关拓扑（如 100kHz LLC）步长太大波形失真甚至发散，步长太小仿真跑死机，得在求解器类型（变步长/定步长 ode23tb/ode4）和精度间权衡。
  - **离散化与积分抗饱和**：连续域调好的 PI 离散化后相位滞后、加了限幅不加抗饱和（Anti-windup）会严重超调甚至振荡。
  - **小信号扫频 vs 理论公式**：像 LLC 用基波近似（FHA）推的传函在谐振点附近还凑合，偏离谐振频点后和实际开关电路必然有偏差，需要扫频实测（PSIM 用 `AC Sweep`，PLECS 用 `Multitone` 或 `AC Sweep`）再叠加 FHA 理论曲线对比解释。
  - **软件版本兼容性**：Simulink 高版本（如 R2024a）存的模型低版本（如 R2020b）打不开，导出降版本常丢模块参数，开头必须问清对方电脑装的是哪个版本。

### 必问点
1. 电脑装的什么软件和具体版本号，手头有没有已经搭了一半的工程文件或参考论文。
2. 关键电气指标（输入输出电压、功率、开关频率、纹波/THD/动态响应要求）和要出哪些对比工况（比如负载突增突减、输入电压阶跃、不同控制算法对比）。

## 二、电力系统与新能源并网

### 常用工具与核心技术点
- **软件**：DIgSILENT PowerFactory、PSS/E、PSCAD/EMTDC、BPA、ETAP、MATLAB/Simulink、Matpower / Pandapower；优化调度常用 MATLAB + YALMIP + Gurobi / CPLEX、Python + Pyomo / Gurobi。
- **核心分析项**：
  - 潮流计算、N-1 静态安全校验、短路电流计算（三相、两相、单相接地、两相接地，分不同故障点和保护整定校核）。
  - 机电暂态与电磁暂态稳定分析、风电/光伏/储能场站接入系统研究。
  - **新能源高低电压穿越（LVRT / HVRT）**：按国标（如 GB/T 19964 光伏、GB/T 19963 风电、GB/T 36547 储能并网标准——涉及具体标准条款和最新版年份时务必先联网核实）核对不同电压跌落深度下的无功电流支撑系数、有功恢复速率和切机逻辑。
  - 宽频振荡与次同步振荡（SSO）阻抗扫描、电网谐波分析。
  - **综合能源系统（IES）/ 微电网优化调度**：电热气冷多能耦合、储能荷电状态（SOC）约束、碳交易/阶梯碳价、需求响应、不确定性建模（随机规划场景削减、两阶段鲁棒优化 CCG 算法分解、分布鲁棒优化 DRO）。
- **真内行实操坑**：
  - 大场站（比如几十套储能或风机集群）不是随便复制粘贴就能用，汇集线阻抗、箱变参数、并网点短路比（SCR）和每台 PCS 控制参数都要按电气主接线配平，买现成单机模型硬改扩成整场站，调穿越和收敛的时间和重做差不多。
  - 优化调度里经常出现双线性项（比如储能同时充放电冲突、价格乘功率、变效率），必须做大 M 法线性化或 McCormick 松弛，不然 Gurobi/CPLEX 直接报非凸或无解（Infeasible）。

### 必问点
1. 电气一次主接线图、设备参数表（变压器、线路、PCS/逆变器额定参数）全不全，按哪个国标或电网公司标准验收。
2. 优化调度类要问清具体包含哪些设备、时间尺度（日前 24 小时还是日内滚动）、有没有指定求解器和目标函数（经济性/碳排/弃风光率）。

## 三、机械、结构、流体、热与电磁 CAE & CAD

### 常用工具与核心技术点
- **结构/热/流体/电磁 CAE**：ANSYS（Workbench / Fluent / CFX / Maxwell / HFSS / Mechanical）、ABAQUS（Standard 隐式 / Explicit 显式、子程序 UMAT/VUMAT/DLOAD）、COMSOL Multiphysics（多物理场耦合）、LS-DYNA、STAR-CCM+、CST。
- **三维与二维 CAD**：SolidWorks、CATIA、UG/NX、Creo、AutoCAD。
- **真内行实操坑**：
  - **几何清理与网格质量**：客户给的 `stp` / `iges` / `x_t` 装配体经常有破面、微小倒角、干涉重合，不先做几何简化修复根本划不出合格网格；论文级仿真还要做**网格无关性验证**（粗中细三套网格对比）和 CFD 的 **y+ 值控制**（边界层加密）。
  - **非线性不收敛**：大变形、超弹性/弹塑性材料本构、复杂接触（摩擦接触、过盈配合）在隐式求解里极易不收敛，需要调子步长、稳定化阻尼、接触刚度或切换准静态显式求解并校验动能与内能比（KE/IE < 5%）。
  - **多物理场双向耦合与算力耗时**：电-热-流-固耦合（如电池包热失控/液冷散热、电机电磁转矩耦合振动噪声、流固耦合 FSI）极吃内存和核时，动辄跑几小时到几天，绝不能按普通画图工时报价。
  - **材料本构与边界条件来源**：客户常只给个零件图，不给材料非线性曲线、换热系数或真实载荷谱，没这些数结果根本对不上实验。

### 必问点
1. 三维几何模型（`stp` / `x_t` / 原生装配体）是不是已经画好，有没有干涉要重画。
2. 软件版本要求、材料参数和边界条件齐不齐、要做稳态还是瞬态、要不要网格无关性验证和实验数据对标。

## 四、电路硬件与 PCB 设计

- **工具**：Altium Designer（AD）、KiCad、Cadence OrCAD / Allegro、Multisim、Proteus。
- **实操重点**：原理图库与封装核对（引脚定义画反一颗芯片整板报废）、多层板层叠结构、高速信号差分阻抗控制（USB / Ethernet / DDR / CAN / RF）、电源完整性与地平面分割、大电流走线载流与开窗散热、DRC 电气规则检查、BOM 物料可采购性核对、Gerber/坐标/钢网全套制板文件。
- **必问点**：功能框图和核心主控芯片定了没、几层板、板框尺寸和接口位置有没有机械结构限制、只交原理图和 PCB 工程还是含打样调试。

## 五、系统动力学、离散事件仿真与运筹优化

- **工具**：Vensim、AnyLogic、Rockwell Arena、FlexSim、Plant Simulation、MATLAB / Python。
- **系统动力学（Vensim / AnyLogic）**：因果回路图（CLD）极性与 R/B 回路检查、存量流量图排版、量纲单位一致性检查、历史数据校准、政策情景与蒙特卡洛敏感性分析。
- **离散事件仿真（Arena / FlexSim / AnyLogic）**：产线节拍、AGV 路径与死锁、排队系统、到达/服务时间分布拟合（Input Analyzer）、预热期（Warm-up）去除、多重复次数（Replications）置信区间统计、瓶颈工序改善对比方案。
- **启发式优化算法**：车间调度（FJSP / HFSP）、车辆路径（VRPTW / 多目标冷链配送）、选址分配；GA / PSO / NSGA-II / NSGA-III / ACO / 模拟退火 / 禁忌搜索，论文常要求和经典算法做帕累托前沿（IGD / HV 指标）与收敛曲线对比。

## 六、化工、土木岩土与建筑工程

- **化工流程（Aspen Plus / HYSYS）**：核心成败在于**物性方法（Property Method）选型**（如 NRTL / UNIQUAC / Peng-Robinson / ELECNRTL），选错了精馏塔和反应器数据全偏；带循环物流（Recycle）和设计规定（Design Spec）的流程极易不收敛，需设置撕裂流股初值和松弛因子。
- **土木岩土（ABAQUS / FLAC3D / PLAXIS / MIDAS / OpenSees / PKPM）**：地应力平衡（初始位移清零）、本构模型参数（莫尔-库仑 / 修正剑桥 / 硬化土 HS）、分步开挖支护施工阶段模拟、地震波调幅与时程反应分析。

## 七、工程仿真类常见交付物

- 可直接打开运行的完整源文件/工程包（按客户指定软件版本保存）
- 高清波形图、云图、对比曲线、统计报表及导出原始数据（`csv` / `xlsx`）
- 参数配置清单、模型结构与改动/排错说明文档
- 必要时附简要复现步骤或关键答辩问题说明（按报价档位决定是否包含）
