# 数据分析、AI 算法、生信医药、数模与软件开发知识库

这类单子客户最常犯的误区是“GitHub 上不是有开源代码吗”“数据扔进去跑一下不就出图了吗”。核心谈单抓手就是把环境依赖、数据清洗/标注、复现落差、对比消融、算力开销和部署维护边界讲成听得懂的大实话。

## 一、人工智能、深度学习、CV / NLP 与大模型应用

### 高频任务与核心技术点
- 计算机视觉（CV）：目标检测（YOLO 系列改进如注意力机制、轻量化主干、损失函数替换、Neck 改进）、语义/实例分割（U-Net / DeepLab / SAM 微调）、医学影像分割（nnU-Net）、图像分类与缺陷检测、姿态估计、多模态检索与生成。
- 时序预测与表格机器学习：LSTM / GRU / TCN / Transformer 变体（Informer / PatchTST / iTransformer / TimesNet）、图神经网络（GNN / GCN / GAT）、LightGBM / XGBoost / CatBoost 集成学习 + 贝叶斯超参优化（Optuna）+ SHAP / LIME 可解释性分析。
- NLP 与大模型（LLM）落地：BERT/RoBERTa 文本分类与命名实体识别、开源大模型 LoRA / QLoRA 微调、RAG 检索增强生成（分块策略、Embedding 选型、Rerank、幻觉评估）、Agent 工作流搭建与 API 集成。
- 实操坑（核心工作量来源）：
  - 论文源码复现极易踩坑：GitHub 论文仓库常缺预处理脚本、依赖老旧 CUDA/PyTorch 版本报错、论文里没写全的数据增强和学习率细节，环境配通和跑出接近原文的指标往往比写新模块还耗时间。
  - 数据才是大头：客户发来的图片常缺标注（VOC / COCO / YOLO 格式不统一）、类别严重不平衡、存在模糊/重复脏图，清洗和转换标注全是工时。
  - 不能只跑一个模型交差：论文和毕设基本都要做多组 Baseline 对比实验和逐模块消融实验（Ablation Study），每次改模块都要重新训一遍，还要统一评估指标（mAP@0.5 / mAP@0.5:0.95 / F1 / Dice / RMSE / MAE / R2）、算参数量 Params 和计算量 GFLOPs、画 Grad-CAM 热力图或混淆矩阵。
  - 算力与时间成本：大模型微调、医学 3D 影像或高分辨率多 epoch 训练吃高端 GPU 显存和卡时，必须算进报价和周期。

### 必问点
1. 数据集现在齐不齐、样本量多大、标注做好了没有（什么格式）。
2. 是纯跑通一套模型出指标，还是论文级别的“改进创新点 + 多组对比 + 消融实验 + 完整可视化图表”，自己电脑有没有显卡、需不需要交付后远程帮你配通本地环境。

## 二、医学统计、卫生经济学与生物信息学

### 核心方法与专业切入点
- 临床与医学统计（SPSS / R / SAS / Stata / GraphPad）：
  - 基线特征三线表（Table 1，正态/非正态分布判断、t 检验/秩和检验/卡方/Fisher 精确检验）。
  - 生存分析（Kaplan-Meier 曲线 + Log-rank 检验、单因素与多因素 Cox 比例风险回归、PH 假定检验、竞争风险模型 Fine-Gray）。
  - 临床预测模型（LASSO 特征筛选、Logistic / Cox 建模、列线图 Nomogram、ROC 曲线与 AUC、校准曲线 Calibration、决策曲线 DCA、临床影响曲线 CIC、内部 Bootstrap 或外部数据集验证）。
  - 观察性研究混杂控制（倾向性评分匹配 PSM / 逆概率加权 IPTW、匹配前后 SMD 平衡性核对）。
  - 孟德尔随机化（MR：TwoSampleMR、IVW / MR-Egger / Weighted Median、异质性 Cochran Q、多效性 MR-PRESSO、留一法敏感性）与 Meta 分析（固定/随机效应模型、森林图、I² 异质性检验、亚组分析、漏斗图与 Egger 发表偏倚）。
- 药物经济学与卫生技术评估（R / TreeAge / Excel）：
  - 决策树模型（短期急性干预）、马尔可夫模型（Markov，长期慢性病状态转移与半周期校正）、分区生存模型（PSM，肿瘤三状态 PFS/PD/Death，常用参数生存分布 Weibull / Log-normal / Log-logistic / Gompertz 拟合外推）。
  - 核心产出：成本-效果分析（ICER、净货币获益 NMB）、单因素敏感性分析（龙卷风图 Tornado）、概率敏感性分析（PSA 蒙特卡洛抽样出成本-效果平面散点图与可接受曲线 CEAC）。
- 生物信息学（R / Linux）：
  - 公共数据库挖掘（TCGA / GEO / GTEx / SEER 临床库）、批量下载与批次效应校正（ComBat）、差异表达分析（DESeq2 / edgeR / limma，火山图与热图）、富集分析（GO / KEGG / GSEA）、WGCNA 共表达网络、免疫浸润（CIBERSORT / ssGSEA）、单细胞转录组（Seurat 质控过滤、降维聚类 UMAP、手动细胞注释、拟时序分析 Monocle、细胞通讯 CellChat）。

### 真内行隐性坑与必问点
- 医学数据最费时间的是原始病历表里的乱填文本、日期格式混杂、失访编码不清、多重插补缺失值；单细胞和生信挖掘吃大内存服务器和参考数据库版本。
- 必问：原始数据是不是已经录成规范电子表、结局事件和随访时间字段全不全、目标期刊/学校有没有规定必须用 R 还是 SPSS、需要交结果图还是带完整可复跑代码。

## 三、数学建模与运筹数据竞赛（国赛 / 美赛 / 研赛）

- 高频模型：评价决策类（AHP 层次分析法 + 一致性检验 CR < 0.1、熵权法 EWM、CRITIC 权重、TOPSIS 优劣解距离法、灰色关联 GRA、模糊综合评价、数据包络分析 DEA / Malmquist 指数）、预测类（灰色预测 GM(1,1)、时间序列 ARIMA/Prophet、机器学习集成）、机理与优化类（微分方程 SIR/SEIR/Lotka-Volterra、多目标规划、元胞自动机、蒙特卡洛模拟）。
- 实操注意点：竞赛单时间极紧（通常 48 到 72 小时），绝不能随便接下做不完的题；模型必须紧扣题目给的附件真实数据，灵敏度分析和误差检验比堆砌花哨名词更重要。

## 四、软件开发、全栈系统、爬虫、逆向与自动化脚本

### 核心工作量与防扯皮边界
- Web 全栈 / 小程序 / 管理系统 / 桌面工具：前后端技术栈（Vue / React / Next.js / FastAPI / Django / Spring Boot / Electron / PyQt）、数据库设计、权限与登录鉴权、接口联调、打包部署。
  - 最大雷区：需求蔓延（Scope Creep）。客户嘴里的“很简单一个小程序/后台”，实际暗含注册登录、角色权限、支付回调、短信/地图第三方接口、后台管理、导出报表、服务器备案与部署运维。报价前必须把页面清单和功能点锁死。
- 数据采集、爬虫与自动化：Scrapy / Playwright / DrissionPage / 抓包分析、动态渲染、滑块/验证码、JS 加密签名与反爬策略、代理 IP 池、断点续传与入库清洗。
  - 关键事实：有强反爬或登录态校验的站点不能按普通静态网页爬虫估工时；目标网站如果后续改版升级反爬，维护属于额外运维范畴，不在一次性交付内；代理 IP、打码平台或第三方 API 费用需明确谁出。
- 脚本与办公自动化：Excel 批量处理、PDF/Word 解析提取、定时任务、跨平台接口对接。

### 必问点
1. 具体的页面/功能清单或目标站点链接发一下，有没有原型图或参考模板。
2. 只要源码自己跑，还是要连带服务器部署上线（域名/服务器/第三方付费接口客户自己提供还是另算）。
3. 交付验收标准怎么定（具体字段数量、并发要求、支持哪些系统环境），后续功能改动怎么算。
