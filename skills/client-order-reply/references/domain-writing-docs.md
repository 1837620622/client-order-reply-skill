# 文书写作，报告与学术材料知识库

这类单交付的是文字和材料，最怕的是要求不清导致反复改。先把格式要求，篇幅，评审对象问清。

## 一、申报书与项目材料（基金，大创，挑战杯，课题，企业项目申报）

- 常见需求：按模板写申报书，研究内容和技术路线，创新点，可行性分析，预算表，进度安排，前期基础。
- 实操重点：严格按当年模板和填写说明，字数和格式限制要逐条核对，技术路线图要和研究内容一一对应，创新点写具体不写空话，预算科目按通知里的口径。
- 必问点：哪一类申报，当年的通知和模板，截止时间，前期成果有哪些，研究方向是不是已经定了，只要文字还是要技术路线图和预算表。

## 二、调研报告，行业报告与商业计划书

- 调研报告：问卷设计，访谈提纲，数据整理分析，结论建议，数据要有来源。
- 行业研究：市场规模，竞争格局，产业链，政策梳理，数据引用要写出处，没有可靠数据的不编。
- 商业计划书：项目介绍，市场分析，商业模式，竞争分析，财务预测，融资需求，比赛用的要符合比赛评分标准。
- 必问点：给谁看（老师，比赛评委，投资人，领导），篇幅，有没有模板，数据有没有现成的。

## 三、论文配套与学术写作

- 开题报告，文献综述，研究方案：选题方向，研究现状要引真实文献，研究方法和技术路线写清楚。
- 方法和结果部分：配合数据分析或仿真结果写，图表编号，单位，格式按学校或期刊模板。
- 翻译和润色：中英互译，专业术语统一，期刊投稿语言润色，按目标期刊风格。
- 查重和 AIGC 检测：各家检测系统结果不同，不承诺具体比例，能做的是按原意改写表述，结果以客户学校指定的系统为准。
- 红线：引用必须是真实存在的文献，不编数据，不编文献。
- 必问点：学校或期刊的格式要求，字数，参考文献格式（GB/T 7714，APA），有没有指定的检测系统。

## 四、图表与演示材料

- 技术路线图，流程图，框架图：Visio，draw.io，PPT，亿图。要和正文内容对得上，配色和字体统一。
- PPT（答辩，汇报，路演）：先要大纲和内容，页数，时长，模板偏好。
- 科研绘图：见 domain-academic-business.md 第三节。
- 必问点：用在什么场合，页数或尺寸，有没有模板和配色要求，要源文件吗。

## 五、专利，软著与说明书

- 专利交底书：技术方案，背景，有益效果，附图，权利要求的层次。正式申请由代理机构办理，这里只做交底材料和技术描述。
- 软著材料：源代码文档（按要求页数），用户操作说明书，截图。
- 必问点：技术方案定没定，有没有附图，提交给谁。

## 六、本领域常见交付物

Word 文档（按模板排版），PDF，技术路线图和流程图源文件，PPT，参考文献列表，修改说明。
