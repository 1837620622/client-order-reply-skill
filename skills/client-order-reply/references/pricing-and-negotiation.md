## 一，没让报价时

只有用户说 报个价，这单报多少，给他个区间，报1200怎么写，按800谈，才写价格。用户只说 怎么回，帮我回，正文零金额，零区间，零定金数，零 几百块一两千 这类价位词。信息不全先要文件任务书，连预算都不用急着问。基本清楚而客户问多少钱，先把技术细节，隐性工作量，交付物讲到位，压下 现成代码白菜价 的预期，再礼貌问预算或想做哪一档，见第九节。能先问预算就先问，客户报了数按他的数配范围，客户说 你先报 再报，报时带档位。

## 二，五维核价

报价的顺序是先量工作量，再看用途，最后才挪吉利数（用户 2026-11-23）。价格由工作量定，用途只在工作量算出的数上往上或往下调一点，吉利数只是最后挪尾数的小技巧，不能拿来定价，也不能拿来抬价。不拍脑袋，不照抄示范数字，必要时联网核同类行情。
1. **有效工时**。前期读任务书文献，配环境，取数（Wind，CSMAR 提取，爬虫，翻年鉴补缺），清洗匹配缩尾核口径。建模调试，调参收敛，排错，处理不显著或偏离理论，多工况，对照组，消融，稳健性。交付包装，论文图，三线表，可复跑代码注释，改动说明。修改单独留工时，经验帖说占总工时 15% 到 25%（corpus.md 五）。
2. **技术门槛**。常规 1.0x，常规统计绘图，基础问卷，干净数据单回归，简单脚本。专业细分 1.3x 到 1.8x，金融实证全套，三表DCF，PSIM Simulink 典型仿真，医学统计药经，深度学习改进消融，CAE 稳态。高难稀缺 2.0x 到 3.5x 以上，场站并网高低穿（PowerFactory，PSCAD，PSS/E），非线性接触 UMAT 多物理场，量化框架实盘接口，衍生品蒙特卡洛和评分卡，顶刊冷门复现，复杂逆向或完整系统。
3. **硬成本**。付费数据库，GPU 和多核求解时长，重型软件环境。
4. **加急**。充裕 1.0x，72 小时内加 25% 到 50%，24 到 48 小时救火通宵周末加 50% 到 100%，并且说死资料几点前给齐。加急费在报价时就说清，写成熬夜和挤掉别的单的成本，客户一急才临时加价会被当成趁火打劫（Kahneman 等 1986，corpus.md 五）。
5. **返工和教学**。客户隐含要求 必须显著，必须贴合某篇论文，按导师意见反复改，工作量容易翻倍，算进溢价或限定修改轮次。装软件，逐行解释，答辩陪练单独加档或算进总价。
工时乘接单系数 1.2 到 1.5，熟活需求清偏低，生活需求模糊偏高（经验帖，corpus.md 五）。

**用途系数（用户 2026-11-23）**。同样的工作量，用途不一样价不一样。用途不知道先问一句，问法见下面示范，判断依据见 client-scenes.md。下面的系数是用户的经验方向加我的推断，具体数没核实过，按实单慢慢校。

| 用途 | 系数参考 | 为什么 |
| --- | --- | --- |
| 学生论文或课程里的一部分，只做其中一块，比如只跑回归，只画图，只调一个模块 | 0.8 到 1.0 | 学生预算紧，量也只算这一块，可以稍低，但不低于工时底价 |
| 学生课程作业整套 | 1.0 | 贴学生常见预算，两档就够 |
| 毕业论文或毕设整套 | 1.0 到 1.2 | 导师反复改，答辩追问，修改工时多 |
| 期刊投稿，科研课题 | 1.2 到 1.5 | 审稿意见回来常要补实验，口径要求严 |
| 工程款，企业项目，甲方验收，单位经费 | 1.5 到 2.5 以上 | 付的是项目钱不是生活费，要验收标准，测试记录，说明文档，出问题责任重，售后长，不用学生单锚点 |

几条要守住的。
- 用途只是调，工作量才是底。学生单的一部分便宜，是因为量小加系数低，不是因为是学生就随便降，算出来工时底价以下照样不接。
- 工程单价高，是因为交付标准和责任真的更重，价里要看得见多给的东西，验收文档，测试记录，售后天数，不能同样的东西只因为是公司就翻倍。
- 客户说是学生其实是项目，或者说一小块其实是整套，按实际看到的工作量和交付标准算，不按他自己说的身份算。
- 用途一时看不出来，只问这一件，别先报价。

问用途的示范（都是示范不照抄）。
- 这个是你课程或者毕设里其中一块要用的，还是项目上要交付给甲方的，用途不一样要做到的程度差挺多，我按你的情况来定。
- 学生只要一部分。这块如果只是论文里的一部分，我就按这部分的量给你算，不用整套的价。
- 工程单。这单是项目上要交付验收的，除了把模型跑通，测试记录和说明文档我也一起整理好，验收那边问到哪块都有依据。

**工作量怎么落成数（用户 2026-11-23）**。报价前在核价备忘里一步步写出来，不跳步。
1. 拆清单。把要交的东西一项项列出来，每项写估计小时数，前期读任务书和配环境，取数清洗，建模调试，出图出表，交付包装，沟通，修改按总工时加 15% 到 25%。拆不出来说明需求还没清楚，先问，不报价。
2. 工时乘【你的时薪】得到基础价，再乘技术门槛，加硬成本，乘加急。
3. 乘用途系数，得到目标价。
4. 开口价在目标价上留一成到两成砍价空间，底价按工时乘最低能接受的时薪，底价以下不接。
5. 最后三个数各自挪到最近的带8的数，见第六节。

核价备忘示范（时薪按 80 元示范，换成用户自己的）。客户要 Stata 基准回归加两个稳健性检验，论文里一部分。清单，读变量表和数据 1 小时，清洗缩尾 2 小时，基准回归和两个稳健性 3 小时，三线表和结果说明 1.5 小时，沟通 0.5 小时，修改按 20% 加 1.6 小时，共约 9.6 小时，基础价约 770。常规门槛 1.0，不加急，学生一部分系数 0.9，目标价约 690，挪成 688。开口 788，目标 688，底价 588。同样的量如果是企业项目交付，系数 1.8 左右，目标约 1390，挪成 1388，再加说明文档和测试记录的工时重算。

## 三，工作量档位锚点

内部校核用，不是死价表。毕业季前后单多经验上能报高些，未核实。

| 档 | 典型耗时和范围 | 原则 |
| --- | --- | --- |
| L1 轻量 | 1 到 3 小时，单个报错，小修，几张规范图 | 设最低门槛，别报连沟通成本都不够的价 |
| L2 单模块 | 半天到 1.5 天，基础回归，单回路仿真，单脚本 | 含完整工时加一次小改，区分只给结果和给可复跑源码 |
| L3 中型 | 2 到 4 天，完整实证，三表DCF，多工况仿真，算法复现加消融 | 撑得住 2 到 4 天，拆基础版和完整版 |
| L4 重型 | 5 到 10 天，场站并网，多物理场，量化系统，全栈 | 不按小单估，分阶段验收付款 |
| L5 长周期 | 2 周以上或跟着导师甲方迭代 | 拆里程碑，定金，阶段验收，终稿，不一口价包无限改 |

学生单成交锚点和丢单原因见 real-orders-review.md，闲鱼学生单多在 150 到 1500，报到客户预算 3 倍以上基本直接丢。

## 四，分档

- 给两三档，别只报一个高价，让客户自己选落点（corpus.md 六.3，丢单常见是超预算太多）。问题从 值不值 变成 哪个最划算。课程作业两档就够。
- 最想成交的放中间，从最高档往下介绍。倍数参考，想推中档 1x，2.2x，5x，想推顶档稳拿单 1x，1.5x，1.75x（Stark，经验帖，corpus.md 五）。学生单最低档贴着学生常见预算。
- 档名用大白话按用途起，只改报错，改好加核对，整套加讲解，或 能跑通，能答辩，能复现交接，不用旗舰版金银铜。
- 高档要多给看得见的东西，不能只靠贵。讲解答疑最能抬档，好评最多夸耐心，讲解细，讲原理，额外问题也教（corpus.md 六.2），放进中高档。其他是源文件和可复跑包，参数说明表，结果解读稿，答辩可能被问的问题清单，修改轮次，售后天数，数据来源表。按客户类型给，毕设加答辩前讲一遍，期刊加审稿意见补实验，工程加测试记录和说明文档。
- 每档写清多给了什么，客户比的是东西。降价就降档，不降单价。

## 五，报价怎么说

- 像顺嘴说出来的（用户 2026-11-23），价格嵌在一句话里，前面是做什么，后面是含什么或下一步，不列项目单价合计。
- 顺序是难点和交付，价格，这个价对他的好处，下一步。好处说他关心的，数据有来源经得起答辩追问，图表直接放论文里能用，代码能复跑后面改也方便，真的才说。
- 一句话说清这个价包含什么，范围内不加钱，加量才另算并且事先说，返修是我的问题不加钱（用户 2026-11-23，corpus.md 六.1，买家最怕中途加钱）。加急，修改轮次，不包含的东西报价时一次说全，成交后不再一项项冒出来，分步加价 drip pricing 会让人觉得被宰（corpus.md 五）。
- 信息不全不报死价，说 按常见情况大概X到Y，看完文件和数据量再报准价。报区间时下限就是目标价，不是底价。
- 有真优势就实在讲，有 CSMAR 就说数据按规范口径从库里导，有好显卡就说调参搜得全，前提是真有。
- 不先收订金再谈价，价谈定再付定金（corpus.md 六.3）。本来就是先付一半定金，客户问 先付一半行吗 顺着答应。
- 示范。这单我帮你把模型搭好，两个控制环调到满足题目要求，能直接跑的工程文件和全部波形图都给你，范围内改都不加钱，大概1288到1688，主要花在调参和核对波形上。

## 六，吉利数（用户 2026-11-23）

- 吉利数只是报价里的一个小技巧，价格还是工作量定（用户 2026-11-23）。先按五维和用途算出目标价，再挪到最近的带8的数，挪动不超过目标价的5%左右，往上挪太多就往下挪，2700 报 2688，2850 报 2888，2300 报 2288 或 2388。不能为了凑8把价往上抬一档。常用 888，1288，1688，1888，2588，2888，3688，3888，4888，5888，6888。尾数和重复位不用4，2400，1440 换成 2388，1388。
- 开口价，目标价，底价三个数报前定好，都用吉利数，写在核价备忘里，比如开口3888，目标3288到3588，底价2888。
- 为什么管用。中文价格广告尾数偏爱8躲开4，台湾实验 888 比 777 更愿意买，8个装愿意多付钱，民宿带8订得更多评分更高，新加坡高价商品也用吉利尾数，人在焦虑失控或碰上考试答辩这种大事时拉动更明显。带8的数不是整数，听着像算过的，对方还价幅度更小。出处见 sources.md 吉利数一节。
- 懂行的老师和企业客户更看重依据，吉利数后面照样跟一句怎么算的。吉利数撑不起烂交付，吉利属性的东西出问题客户失望更大，报了2888就要做出2888的样子。
- 祝福规则见 SKILL.md 硬规则 13，下面所有带祝福的句子都是示范不照抄。

## 七，砍价和让步（用户 2026-11-23）

**报价前准备**。定好开口价，目标价，底价，底价以下不接。列两三样能换的，砍范围（机制检验，对比模型，说明文档），砍服务（讲解，修改轮次），砍交期（不加急），客户能给的（先付全款，介绍同学，交期放宽）。列两三样对自己几乎不花功夫但客户看得见的小东西，答辩前帮他过一遍，一次小修改不另收，附一份参数说明，用来代替降价，要花大功夫的别当添头送。

**第一次砍**。不马上松口，让步来得太快对方对东西的估值和成交满意度都会降。先接住，再问哪块超了或者心里价位，你心里大概想落在多少，他说出数之前自己不先降，也不先报底价。客户报了低价不围着他的数还，说清他那个价能做到哪一步，再说整套最低多少。

**让步**。降价只换东西，砍范围或修改轮次，不白降单价，直接降价等于告诉对方初报价是虚的（corpus.md 五）。修改从两轮改一轮是客户最容易接受的降价方式之一，大方向他先跟导师定好。让步一次比一次小，都落在吉利数上，3888，3688，3588，3568，第一次让200，第二次100，第三次20，对方会觉得快到底了。两三轮到底，说 这是最低了 必须是真的，说完不再松。抹零可以，但换东西，或者零头不抹送一样小服务。

**守价时短而暖**（用户 2026-11-23，corpus.md 六.9）。真人守价多用很短的话，用户要热情，所以守价短而暖，用让步换东西，不硬顶，不讲大道理。

**收尾**。谈定马上落到下一步，付定金，发文件，开工时间，祝福可以放这一句。谈不拢热情收住留话头，见 negotiation-psychology.md 留话头一节，不追，不降到底价以下。

## 八，常见砍法和砍价类型

| 客户说 | 接法 |
| --- | --- |
| 试探，上来就 最低多少 | 不报不让，拉回要做什么，让他先发材料。最低多少得看你要做到哪一步，同样是跑回归，只出结果和带稳健性加解读差得挺多，你把任务书发我看一眼，我按你要的给你算 |
| 便宜点吧 | 先问哪块超了或心里价位。可以商量，你心里大概想落在多少，说个数我看看哪块能调 |
| 小刀，报价后砍一成左右 | 小让一点换一个条件。2600有点紧，2688吧，今天定下来我今晚就开始导数据 |
| 大刀，砍三四成，或报了远低于目标的数 | 说清那个价能做哪部分，给一个靠近目标的吉利数。1500的话我只能做数据清洗和基准回归这两块，后面的检验和解读做不进去，你要是这两块就够用，1588我就接了 |
| 屠龙刀，砍一半以上 | 礼貌放手留话头。500这个价我做不了，差得有点多，后面预算能松一些，或者只想先做其中一小块，再来找我 |
| 别家只要几百 | 不说同行坏话，让他对一下含什么。能理解，差这么多换我也会犹豫，你可以问问他那个价里含不含数据来源，稳健性检验和后面的修改，对得上再比会准一些 |
| 学生没钱 | 砍范围保核心，或者价不动送小服务 |
| 这个很简单吧 | 用事实轻轻点破，看着改一个参数，后面哪几块要跟着重配平重收敛，真简单的话发文件看一眼，费用自然低 |
| 先免费做一版看看 | 核心产出不免费，可以免费看一眼给诊断方向，或拆出极小的第一步先付一点 |
| 能保证过，保证显著吗 | 不答应，说清哪些由数据和老师决定，列能验收的，本地能复跑，口径按文献规范，结果和图表一致 |
| 一口价我就定了 | 在底价以上可以答应，换一个条件，比如今天付定金 |
| 嫌贵之后没下文，像借口 | 降价也不会成交，问一句卡在哪，问过不回就收住 |
| 第三次还在磨 | 2688真的是我能给的最低了，再往下我做着也不踏实，合适的话你把任务书发我，今天就能开工 |

小刀 5% 到 15%，大刀 15% 到 40%，40% 以上屠龙刀，是闲鱼卖二手的说法，未核实是否适用所有单子。节奏三步，第一次守价问心里价位，第二次小让换条件，第三次给最后的数（经验帖，sources.md 砍价话术调研）。全网最低，好几个人在问先付先得，我这单亏本，老板定的我也没办法，爱买不买 违反红线不用。

## 九，问预算和工期（用户 2026-11-23）

起因是叶片凝固时间单，我写了 预算心里有个数吗，用户说太冷漠。问预算工期是在帮他配方案，要像学长替他想办法，不像审问。
1. 先接住他刚说的事，用他的词和数字，他说 每组15个，先回 15个一组挺好整理的。
2. 给一句替他着想的理由，问预算是为了配最合适的做法，问工期是为了按他的进度排。
3. 带 方便的话，大概，跟我说下，语气词一段最多2个。
4. 一条最多问两件，预算和工期可以一起问，问完就停。
5. 冷问法见 anti-ai-style.md 黑名单，不说 您 和 亲。
- 冷。你这边大概什么时候要，预算心里有个数吗，我按这个给你配个合适的做法。
- 暖。15个一组挺好整理的，叶尖的点定好以后每个算例照着读就行。教程和我直接帮你提数据都能做，看你哪种更省事。方便的话跟我说下大概什么时候要用，预算大概多少呀，我按你的情况帮你配个最划算的做法。

## 十，谈单禁忌

1. 不说自己做得很快，一两天就能出会把价拉垮，按含清洗，调试，核对，修改缓冲的完整周期说。
2. 不主动提退款，客户问了再按阶段说，没动工全退，做到哪一步按已完成扣。
3. 不给往后拖的台阶，你下个月再找我也行，不急你慢慢比价，你先考虑想好了发我。
4. 不连环追问，问完预算或要完文件就收住。
5. 不接模糊一口价，按导师意见一直改到定稿 这种，提前说清小调和换题换模型大加实验的边界，导师提的修改约定几次以内包含，超出另算（corpus.md 五）。
6. 谈完价后面的回复只谈事，不是每条都提价格，差评最常骂句句谈钱（corpus.md 六.4）。

## 十一，用真实资源牵住客户（用户 2026-11-22）

谈的时候顺带说出真有的东西，数据库，年报和行业数据补齐并标来源，软件环境，答辩前讲解，修改售后，客户会觉得找我不只是买一个模型。这些放进中高档，讲清都在价格里，砍价时也拿它们换不降单价。客户嫌贵或说先自己做，热情收住，留下 数据找不到，跑不通，卡住了随时找我 的钩子，不追问不降价。红线，只亮 real-orders-review.md 里确认有的，不编数据库和案例，不说包找到，免费只到看一眼给方向。


## 十二，成交后付款流程（用户 2026-11-23）

价谈定后马上落付款，不拖。
